## 一、项目概述

### 1.1 项目背景
家庭拥有多品类咖啡豆，需可视化管理豆子的养豆状态、在喝/喝完进度，支持AI拍照入库、风味标签图标化、双人简单评价。参考BeanBook App的货架视图与图形化详情页风格。

### 1.2 目标用户
- 主要用户：咖啡爱好者本人
- 次要用户：毛小毛（太太，共享库存，各自评价）

### 1.3 核心价值
- 一眼看清所有豆子的状态（养豆中 / 在喝 / 抓紧喝 / 喝完）
- 拍照即入库，AI自动识别豆袋信息
- 风味标签配统一风格图标，美观直观
- 两人各自打分，记录口味偏好

## 二、用户角色

| 角色 | 权限 |
|---|---|
| 家庭成员（本人） | 全部功能：入库、编辑、状态变更、评价、风味维护、品牌维护 |
| 家庭成员（毛小毛/太太） | 全部功能：共享同一库存，可入库、状态变更、评价；评价独立署名 |

> 两人通过微信openid区分身份，数据天然共享，无需额外账号体系。

| 排序 | 默认按状态优先级（在喝>养豆中>已喝完）+ 烘焙日期；可切换按添加时间 | P1 |
| 搜索 | 常驻搜索框，按品牌名、豆名、产区、豆种实时过滤 | P1 |

- 风味图标（最多3个，横向排列）

### 3.2 AI入库流程

**入口：** 货架页右上角 ➕ → 添加豆子页（四个入口按钮）

| 选项 | 说明 | 优先级 |
|---|---|---|
| 📷 AI拍照识别 | 默认选项，进入拍照页拍豆袋 | P0 |
| 🖼️ 相册批量导入 | 从相册选择豆袋照片批量识别 | P1 |
| ✏️ 手动录入 | 纯手填表单，不用AI，直达确认编辑页 | P0 |
| 🔗 粘贴商品链接 | 粘贴淘宝/微店链接，AI抓取信息，经AI识别中页转确认编辑 | P2 |

#### 3.2.1 四步入库流程（P0，原型已定稿）

```
① 拍照 → ② 确认上传 → ③ AI识别（动画过渡）→ ④ 核对入库 → 货架
```

**① 拍照页（pages/add/camera）**

| 元素 | 说明 |
|---|---|
| 取景器 | 深色取景框，四角对焦括号，中央豆袋占位提示 |
| 快门按钮 | 拍摄后进入确认照片页 |
| 相册入口 | 左下角，带最近照片数量角标，跳确认照片页（相册路径） |
| 闪光灯/翻转 | 系统相机能力 |
| 返回（✕） | 放弃本次添加，回货架页 |

**② 确认照片页（pages/add/upload）**

| 元素 | 说明 |
|---|---|
| 步骤进度指示 | ① 拍照 → ② 确认上传（高亮）→ ③ AI 识别 → ④ 核对入库 |
| 大图预览 | 当前选中照片 |
| 照片缩略条 | 最多3张；点选切换「识别主图」（决定AI以哪张为主识别）；可追加 |
| 返回（‹） | 回拍照页重新拍摄 |
| 底部按钮（统一规格：高44px / 圆角12px / 间距12px） | [重新拍摄]（灰）+ [✨ 确认使用]（绿，进入AI识别中页） |

**③ AI识别中页（pages/add/processing，动画过渡）**

- 深色页面 + 冲煮动画（10秒循环）：3颗咖啡豆碎成粉末 → 落入V60滤杯 → 细口壶注入热水 → 咖啡滴入玻璃分享壶、液面渐升
- 提示文案轮播：「正在识别品牌…」「正在提取豆名与豆种…」「正在识别产区与处理法…」「正在匹配风味标签…」「整理识别结果，即将完成…」
- 跳过按钮：识别完成后自动进入核对页，也可点按直接查看结果
- 动画实现：H5原型为纯CSS；小程序为 CSS 动画 + （可选）Lottie，逻辑不变

**④ 核对入库（确认编辑页，pages/add/confirm）**

- 顶部「本次照片」条：点选封面图（橙色描边+✓+封面徽标），封面即货架卡片照片
- AI识别提示条 + 识别结果表单
- 联想快捷标签：豆种（瑰夏/74158/铁皮卡/波旁/SL28/卡杜拉）、处理法（水洗/日晒/蜜处理/厌氧日晒/湿剥法）、国家（常用国旗标签）点击即填
- 字段顺序与详情页属性区对齐：品牌（AI匹配条）→ 豆名 → 国家/产区 → 豆种/处理法 → 海拔/克重 → 烘焙度 → 冲煮方式 → 烘焙日期 → 风味标签 → 描述
- 「入库」按钮 → 回货架页，新卡片置顶带「NEW」角标

**编辑复用模式（同一页面双形态）：** 确认编辑页既用于入库核对，也从豆子详情页 ⋯ 菜单「✏️ 编辑豆子」复用。两种形态差异：

| | 入库核对形态 | 编辑形态（从详情进入） |
|---|---|---|
| 标题 | 确认豆子信息 | 编辑豆子 |
| 主按钮 | 入库（→货架） | 保存（→详情，同步更新详情页展示） |
| 步骤条/AI识别提示条 | 显示 | 隐藏 |
| 返回（‹） | 回确认照片页 | 无变更：直接回详情；有变更：弹「是否保存修改？」对话框（保存/不保存/取消），不保存则还原修改 |

**AI识别字段：**

| 字段 | 说明 | 必填 |
|---|---|---|
| 品牌 | 烘焙商/品牌名，自动匹配内置品牌库 | 是 |
| 豆名 | 产品名称 | 是 |
| 国家 | 如「埃塞俄比亚」（带国旗emoji展示） | 是 |
| 产区 | 如「耶加雪菲」，与国家分开识别 | 是 |
| 豆种 | 如「瑰夏」「74158」「铁皮卡」 | 否 |
| 处理法 | 水洗/日晒/蜜处理/厌氧等 | 是 |
| 海拔 | 如「2200m」 | 否 |
| 烘焙度 | 浅/中浅/中/中深/深 | 是 |
| 克重 | 如「200g」「680g」 | 否 |
| 烘焙日期 | 如「2026-08-20」 | 是 |
| 风味描述 | 烘焙商标注的风味文字 | 否 |
| 风味关键词 | 从风味描述拆分的关键词数组 | 否 |

**入库后：**
- 写入beans集合
- 根据烘焙日期+烘焙度+冲煮方式自动计算状态
- 跳转回货架页，新卡片顶部显示，带「NEW」角标

### 3.3 豆子状态管理

**四状态模型（核心简化）：**

```
养豆中 ──(养豆期到/手动)──> 在喝 ──(手动)──> 喝完
  ↑                        │(可选手动)        │
  └──────(重新养豆)─────────┴──> 抓紧喝 ──>──┘
```

| 状态 | 颜色 | 进入条件 | 说明 |
|---|---|---|---|
| 养豆中 | 黄色 #FAAD14 | 入库时烘焙日期距今 < 养豆期 | 等待排气完成，系统自动计算，到期自动提示 |
| 在喝 | 绿色 #52C41A | 养豆期到自动转入，或手动点「开喝」 | 正在饮用的豆子 |
| 抓紧喝 | 橙色 #F97316 | **仅手动**（在喝状态下点「⏰ 抓紧喝」次按钮） | 风味衰退期提醒，永不自动进入 |
| 喝完 | 灰色 #9CA3AF | 手动点「喝完」 | 归档，不再显示在默认列表 |

> 货架筛选：含独立「🟠 抓紧喝」筛选项；统计页状态分布中并入在喝段（以橙色子段展示）。

**养豆期规则（自动计算，默认值）：**

| 烘焙月份 | 养豆期 |
|---|---|
| 5-10月 | 20天 |
| 其他月份 | 25天 |

> 养豆期从烘焙日期起算；到期后状态自动从「养豆中」变为「在喝」（打开App时实时计算，无需定时任务）。

**状态变更操作（主按钮一键直达常用状态，可跳过自动计算）：**
- 养豆中 → 在喝：自动（到期）或手动点主按钮「开喝」
- 在喝 → 喝完：手动点主按钮「喝完」（一键直达，跳过抓紧喝）
- 在喝 → 抓紧喝：手动点次按钮「⏰ 抓紧喝」（仅此时显示该按钮，永不自动进入）
- 喝完 → 养豆中：手动点「重新养豆」
- 每次切换，状态条同步变化（色点/文字/底色/右侧文案）

### 3.4 豆子详情页

**顶部区域：**
- 豆袋照片（可左右滑动，最多3张）
- 豆名（大标题）
- 品牌名 + logo（点击进入品牌详情）
- 状态条：状态色点 + 状态文字 + 右侧文案随状态变化（养豆中「还需X天 · 养豆期N天」/ 在喝「200g · 最佳赏味第X天」/ 抓紧喝「200g · 风味衰退期 · 尽快饮用」/ 喝完「200g · 本袋已喝完」）
- 风味图标行：无白底大图标（约2倍尺寸），紧凑排列不重叠（6px间距），水彩插画 + 风味文字衬线斜体

**我的评价区：**
- 我的评分：1-5星
- 毛小毛的评分：1-5星
- 两人评分并排显示，区分身份
- 「评分」按钮 → 底部弹层：**仅显示并可修改自己的评分**（星级可点 + 可填简短感受 + 保存）；对方评分由对方自己打，不可代改

**豆子属性区（4列图标条，原型定稿样式）：**

每项 = 彩色圆角图标底（64px，马卡龙浅色）+ PNG图标（44px，统一缩放）+ 下方文字（数值+标签）；图标已就位于 assets/icons/proposal1/：

| 顺序 | 属性 | 图标文件 | 内容示例 | 底色 |
|---|---|---|---|---|
| 1 | 烘焙日期 | roast_date.png | 2026.08.28 | 浅桃 #FFE5DB |
| 2 | 豆种 | bean_variety.png | 74158 | 浅棕 #F0E4DA |
| 3 | 处理法 | process_method.png | 水洗 | 浅蓝 #D7EBF7 |
| 4 | 产区 | country_region.png | 国家小字（埃塞俄比亚）+ 产区值（耶加雪菲） | 浅绿 #DCEEDA |
| 5 | 海拔 | altitude.png | 2200m | 浅黄绿 #F0F3CF |
| 6 | 烘焙度 | roast_level.png | 浅烘 | 浅金 #FFE9BC |
| 7 | 冲煮方式 | brewing.png / espresso_roast.png / omni_roast.png（手冲/意式/通用按值切换） | 手冲 | 浅琥珀 #FBE4D2 |
| 8 | 重量 | bean_weight.png | 200g | 浅紫灰 #E7E2F1 |

> 入库日期不在属性区展示（入库时间在编辑页/记录中体现）。风味图标行：无白底大图标（约48px），紧凑排列不重叠，衬线斜体风味文字。

**底部操作栏（按钮统一规格：高44px / 圆角12px / 间距12px / 字号14px）：**
- [评分]（金橙 #FF6E20）+ [⏰ 抓紧喝]（白底橙描边次按钮，**仅在喝状态显示**）+ [主状态按钮]
- 主状态按钮随当前状态变化：养豆中→「开喝」(绿 #07C160) / 在喝·抓紧喝→「喝完」(米黄底深棕字) / 喝完→「重新养豆」(灰)
- 主按钮一键直达常用下一状态，不强制经过抓紧喝

**右上角 ⋯ 菜单（更多操作）：**
- ✏️ 编辑豆子（进入确认编辑页「编辑形态」，返回逻辑见 3.2 编辑复用模式）
- ⤴ 分享（待开发）
- 🗑️ 删除豆子（红色，二次确认后删除并返回货架）

### 3.6 风味标签管理

**核心机制：**
- 每个风味标签配一张统一风格的水彩食物插画图标
- 图标由AI（Seedream）生成，生成后永久保存复用
- 本地库已有相同风味时不重复生成
- 用户可维护风味标签，不满意可重新生成

**风味标签维护页：**
- 按分类分组展示：水果类/花香类/甜感类/坚果可可类/香料类/烘焙类/其他
- 每个标签：图标 + 名称
- 搜索框
- 返回（‹）：回货架页
- 右上 ➕：新增标签（进标签详情页）
- 标签详情：
  - 图标大图
  - 名称（可编辑）
  - 分类（可改）
  - 「重新生成图标」按钮 → AI重新生成 → 新旧对比 → 确认替换
  - 「删除」（未被使用时才可删）
- 「新增标签」：输入名称 → 选分类 → AI自动生成图标 → 保存

**预置风味标签（40+）：**

| 分类 | 标签 |
|---|---|
| 水果类 | 草莓、橙子、柠檬、蓝莓、桃子、芒果、菠萝、苹果、葡萄、樱桃、百香果、猕猴桃 |
| 花香类 | 茉莉、玫瑰、桂花、洋甘菊、薰衣草、橙花 |
| 甜感类 | 蜂蜜、焦糖、香草、红糖、糖蜜、枫糖 |
| 坚果可可类 | 榛子、杏仁、黑巧、牛奶巧克力、花生、椰子 |
| 香料类 | 胡椒、丁香、肉豆蔻、肉桂、八角 |
| 烘焙类 | 麦芽、谷物、烟熏、烤可可、饼干 |
| 其他 | 茶感、奶油、发酵感、草本、清爽 |

**图标风格定义：**
- 水彩手绘食物插画
- 白色/透明背景
- 主体居中
- 柔和暖色调
- 无文字
- 统一Prompt：`watercolor illustration of {name}, single object, white background, soft warm colors, hand painted style, minimal, centered, no text`
