- 异形磁贴方案已废弃（用户反馈清除装饰性形状）

### AI识别中页冲煮动画（10秒循环）

3颗咖啡豆晃动碎成粉末 → 落入 V60 滤杯 → 细口壶滑入倾斜注水 → 咖啡滴入玻璃分享壶、液面渐升 → 淡出重来；提示文案轮播 5 条 + 跳过按钮。H5 原型纯 CSS 实现；小程序方案：CSS 动画直接迁移，效果不足时升级 Lottie。

### 风味图标

阶段②用 emoji/色块占位；数据结构保留 `iconUrl`；阶段④用 Seedream 按规格书统一 prompt 批量生成后替换。

## 四、工程结构（阶段②产出）

```
coffeeApp/
├── miniprogram/
│   ├── pages/            # 规格书v1.1的14页（含 stats 统计页、add/camera|upload|processing|confirm、brand/add）
│   ├── components/       # bean-card / attr-icon-bar / rating-stars / flavor-tag / status-badge / photo-strip / brew-animation
│   ├── styles/tokens.wxss
│   ├── api/              # bean.js / brand.js / flavor.js / stats.js
│   ├── mock/             # 各状态豆子样例数据
│   └── utils/            # status.js 养豆期计算 / format.js
├── cloudfunctions/       # 阶段③④填充：recognizeBean / genFlavorIcon
└── docs/
```

- `attr-icon-bar` 组件：图标+底色+数值+标签 四参数数据驱动；冲煮方式按值切图标。
- `utils/status.js` 为纯函数，TDD 开发（养豆期规则表来自规格书 3.3）。

## 五、统计页与 AI 接入设计

### 统计页（pages/stats/stats，原型已定稿）

- 深色汇总头：总克重、品牌数、产区数、豆种数
- 状态分布：三色占比条 + 各状态袋数
- 处理法计数 → **国家分布横条图**（国旗emoji+国名+渐变条+袋数）→ **豆种分布横条图**
- 产区地图：**canvas 2D 风格化世界地图 + 产区标注点**（替代 BeanStats 的 3D 地球仪；WebGL 成本高一个量级，2D 意境接近）
- 底部：烘焙商数 / 袋数 / 产区数 / 豆种数 四指标

### 火山方舟接入（阶段④）

| 用途 | 模型 | 说明 |
|---|---|---|
| 拍照识别豆袋 | `doubao-seed-1.6`（视觉理解，JSON 输出） | 备选降级 `doubao-1.5-vision-lite`；识别字段含国家+产区（拆分） |
| 水彩风味图标 | `doubao-seedream-4.0` | 统一 prompt 沿用规格书 3.6 |

- 云函数 `recognizeBean`：图片云存储 fileID（含识别主图）→ 豆包多模态 → 结构化 JSON（字段表见规格书 3.2.1）→ 自动匹配品牌/风味。识别期间前端停在冲煮动画页，完成后自动跳核对页（保留跳过）。
- 云函数 `genFlavorIcon`：按名称生成水彩图标 → 传云存储 → 写 `flavor_tags.iconUrl`。
- API Key 与 Endpoint ID 放云函数环境变量，不进代码库；识别目标 < 5 秒。

## 六、superpowers 工作流映射

| 技能 | 用在哪 |
|---|---|
| writing-plans | 阶段②③④开工前拆实施计划（吸收上一阶段反馈） |
| executing-plans / subagent-driven-development | 按 P0 任务批执行，每批检查点；阶段② 14 页相互独立部分可并行 |
| test-driven-development | utils/status.js、筛选排序、评分均值、统计聚合等纯函数 |
| dispatching-parallel-agents | 相互独立的页面/组件并行开发 |
| systematic-debugging | 阶段③④联调问题 |
| verification-before-completion | 每阶段收尾真机验证 |
| requesting-code-review | 阶段结束自查 |

注：TDD 适用于逻辑代码；视觉稿阶段靠人工逐屏确认（阶段①已完成）。

## 七、风险与取舍

| 风险 | 对策 |
|---|---|
| 小程序不能内嵌自定义字体 | 中文衬线用 Songti SC/STSong 系统字体 fallback，安卓退化为宋体，可接受 |
| 属性 PNG 图标未到位 | 原型/前端用 emoji 占位（结构已留 iconUrl 位），PNG 到位后直接替换，无代码改动 |
| 3D 地球仪成本高 | 降级为 canvas 2D 风格化地图（本设计已采纳） |
| 冲煮动画小程序性能 | 先 CSS 动画迁移；不足时 Lottie；极端降级为静态插画+加载文案轮播 |
| 风味图标依赖生图 API | 前端先行占位，图标生成集中在阶段④一次完成 |
| 审核类目 | 个人主体建议「生活服务」或「工具 > 信息查询」 |
